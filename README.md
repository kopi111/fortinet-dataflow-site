# FortinetDashboard Data Flow

A simple visual guide showing how security data flows through the FortinetDashboard system.

## Overview

This page explains the data flow in 4 simple steps:

1. **Where Data Comes From** - 4 data sources (Fortinet, Versa, NetBox, MySQL)
2. **What Happens to the Data** - Site Comparison Engine processing
3. **What We Learn** - Results (175 devices, 78 matched, 97 unmatched)
4. **What Staff See** - Security Dashboard output

## Usage

Open `index.html` in any web browser.

## Technology

- HTML5
- CSS3
- No dependencies required
